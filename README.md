# Curious Us（好奇的我們）

**Complex AI, Curious Us｜AI 很厲害，我們帶著好奇去學。**

本專案旨在將全球頂尖人工智慧研究者與實踐者（如 Andrej Karpathy 等）的前沿技術思考與典範轉移，轉譯為所有非程式設計背景的普通工作者、研究生與團隊協作者皆能直接理解並應用的實踐知識。

全系列文章與圖表均採用 **[Creative Commons Attribution 4.0 International (CC BY 4.0)](LICENSE)** 授權釋出，歡迎自由轉載、教學引用與二次創作。
